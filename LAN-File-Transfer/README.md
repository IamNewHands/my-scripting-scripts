# 局域网文件传输

在局域网或手机热点下，与任意设备的浏览器互传文件、图片和文字。扫码即连，无需在对方设备安装任何应用。

> English: [README.en.md](./README.en.md)

## 功能

- **扫码即连**：App 内展示二维码，对方浏览器扫码（或访问链接）即可进入聊天页，无需安装
- **双向互传**：App ⇄ 浏览器，文件、图片、文字双向传输
- **不走流量**：设备间通过局域网直连，不经过任何云端中转
- **文字聊天**：App 与浏览器实时文字互通（WebSocket）
- **图片预览**：图片消息直接在气泡内预览，点击可共享/保存
- **Share Sheet 集成**：从分享菜单直接拖入文件/图片到聊天界面
- **深色模式**：App 端与浏览器端均适配明暗色

## 通信方式

| 链路 | 协议 | 说明 |
|------|------|------|
| 浏览器 → App 文件上传 | HTTP POST | 浏览器直传原始字节 |
| App → 浏览器文件下载 | HTTP GET | 临时路由 `/dl/<id>` 提供下载 |
| 文字互通 / 连接状态 | WebSocket | 双向实时消息 |

## 使用方式

1. 在 App 中打开「局域网文件传输」
2. 点击右上角二维码按钮，或用另一台设备访问页面显示的链接
3. 对方浏览器打开后自动进入聊天页，即可互传文件/图片/文字

## 隐私

- 设备间通过**局域网直连**，数据不经过任何中转服务，**不消耗移动流量**
- 服务端为本地临时 HTTP/WS 服务，会话关闭即清理接收文件
- 不收集、不上传、不分享任何用户信息

## 边界与说明

- 双方需处于同一局域网/热点，纯蜂窝网络下无法使用
- 接收的文件存放在临时目录，**关闭页面（叉号）会删除**；点「最小化」可保留
- 关闭按钮会弹确认提示，避免误触清空接收文件

## 外部域名

- 无（纯局域网直连，不访问任何外部服务）
